낚시 HUD — 인게임 합성 미리보기

실제 리소스팩 PNG 를 플러그인과 동일한 합성 규칙(글리프 + 오프셋)으로 배치해 렌더한 결과입니다. 화면은 640×360 GUI 픽셀(1920×1080 · GUI 스케일 3 기준)이고, 이미지는 2배 확대했습니다.

1. 트로피 파이트 — CHARGE(돌진) · 텐션 82% 위험

거리 트래커(위) · 상태 카드(정중앙) · 콤보(카드 오른쪽) · 물고기 체력/텐션/릴(아래). 콤보는 좌클릭(릴 감기)이면 금색 좌클릭 콤보, 우클릭(릴 풀기)이면 하늘색 우클릭 콤보 로 표시됩니다. 텐션 게이지는 채워진 만큼만 안전(초록)·주의(노랑)·위험(빨강) 색이 드러나고 나머지는 어두운 트랙입니다. 80% 이상이면 퍼센트 자리가 경고 문구로 바뀌어 점멸하지만 바늘과 게이지는 계속 갱신됩니다.

2. 상태 카드 11종

FishState 11개 각각의 아이콘·색·상태명·행동 안내. 문구와 색은 hud.yml / hud_spec.py 에서 바꿉니다.

3. 입질 L/R 클릭 미니게임 — 4클릭(F등급)

4. 같은 HUD, 9클릭(S등급)

키 카드는 28×36(기존 2배)이고, 클릭 수에 맞춰 패널 폭이 자동으로 늘어납니다. 지나간 입력은 초록, 지금 눌러야 하는 입력은 하늘색 테두리+빨강, 남은 입력은 회색. 아래 막대가 제한 시간이고 30% 미만이면 빨강으로 바뀝니다. hud.yml 의 minigame.mode: vanilla 로 두면 이 화면 대신 기존 액션바 표시를 그대로 씁니다.

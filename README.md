# 🎣 InMc-Fishing

**InMc-Fishing**은 마인크래프트 서버의 낚시를 즐거운 RPG 활동으로 바꿔주는 플러그인입니다.

낚싯대를 던지면 단순히 물고기가 잡히는 것이 아니라, **클릭 미니게임**으로 등급별 물고기를 낚고, **트로피 힘겨루기(Fight)**에 도전하며, **도감**에 기록하고, **어망**으로 수집하며, **대회**에 참가할 수 있습니다. 설정 파일만 수정하면 물고기 확률, 보상, 대회 일정까지 서버 관리자가 원하는 대로 바꿀 수 있습니다.

---

## 이 플러그인으로 무엇을 할 수 있나요?

낚시의 전체 흐름을 예시로 설명합니다.

> 1. 물가에 서서 낚싯대를 던집니다. → “입질”이 옵니다.
> 2. 화면에 **L(좌클릭) / R(우클릭)** 버튼이 순서대로 나타납니다. 예: `L → R → R → L`
> 3. 제한 시간 안에 순서대로 클릭하면 **물고기를 낚습니다!**
> 4. 낚은 물고기는 **등급(F~S)**, **크기(cm)** 를 가지며, 드물게 **트로피 / 레어 트로피**가 됩니다.
> 5. 트로피 물고기라면 **힘겨루기(Fight)** 가 시작됩니다 — 좌클릭으로 제압하고, 우클릭으로 릴을 회복하며 물고기를 제압하세요.
> 6. 낚은 물고기는 **도감**에 등록하거나 **어망**에 모아 **랭킹**과 **트로피**를 노립니다.
> 7. 정해진 시간에 열리는 **낚시 대회**에 참가해 서버 최고의 낚시꾼에 도전합니다.

## 주요 기능

### 1. 낚시 미니게임 🎮
입질이 오면 화면에 L/R 클릭 순서가 나타납니다. 제한 시간 안에 순서대로 클릭해야 성공합니다.

- 등급이 높을수록 **클릭 횟수가 늘어나고, 제한 시간이 짧아집니다.**
- 진행 상황이 화면 하단(action bar)에 진행 바와 함께 표시됩니다.
- `/fishing minigame <on|off>` 로 개인별로 끄면 자동 낚시로 전환됩니다.

### 2. 등급 시스템 (F ~ S) 🐟
물고기에는 등급이 있으며, 등급에 따라 **나올 확률과 미니게임 난이도**가 다릅니다.

| 등급 | 나올 확률 | 필요한 클릭 수 | 제한 시간 | 비고 |
|------|-----------|----------------|-----------|------|
| F | 45% | 3번 | 5.0초 | 가장 흔함 |
| E | 25% | 4번 | 4.5초 | |
| D | 15% | 5번 | 4.0초 | |
| C | 8% | 6번 | 3.8초 | |
| B | 4% | 7번 | 3.5초 | |
| A | 2% | 8번 | 3.2초 | |
| S | 1% | 9번 | 3.0초 | 가장 희귀하고 어려움 |

- 이 수치는 `grades.yml` 파일에서 자유롭게 바꿀 수 있습니다.

### 3. 물고기 & 사이즈 📏
- 각 물고기는 **최소/최대/평균 크기(cm)** 를 가집니다.
- 물고기를 낚을 때마다 크기가 랜덤으로 정해집니다. **크기는 어망(Net)에서만 표시**되고, 인벤토리의 물고기 아이템에는 표시되지 않습니다(트로피/레어 여부만 표시).
- 쓰레기(장화, 석탄 등)처럼 크기가 없는 아이템도 존재합니다.

### 4. 대어(Big Fish) & 더블 보상 ⭐💎
- **대어**: 일정 확률로 한 단계 높은 등급으로 승급됩니다. (F→E, A→S / S는 최상위라 승급 없음)
- **더블**: 일정 확률로 보상 아이템이 **2개** 지급됩니다.
- 확률은 `config.yml`의 `rates`에서 조절합니다.

### 5. 낚싯대 시스템 🎣
- 플러그인에 등록된 낚싯대를 들고 낚시하면 **등급별 확률 보너스**가 적용됩니다.
- 기본(보너스 0) 낚싯대 기준 **F등급은 쉬움 · E등급은 노력하면 가능 · D등급은 어려움**이며, 더 좋은 낚싯대일수록 위 난이도가 낮아집니다.
- 기본 제공 낚싯대는 **바닐라 10종**(낡은 나무/평범/대나무/철/금/흑요석/고급/마스터/신화/전설)이며, 이름으로 인식됩니다. 낚싯대 목록·보너스는 `items/rod.yml`에서 관리합니다.
- 낚싯대 능력은 **아이템 lore에 자동 표기**됩니다 (등급 보너스 0이 아닌 것만, 더블/대어/피로도/파이팅 스탯).
- **Fight 스탯(릴 파워/줄 강도/릴 내구도)은 "기본값 + 낚싯대 보너스" 추가값 방식**으로 작동합니다. (기본 릴 파워 30, 줄 강도 100, 릴 내구도 30 — `config.yml` `trophy-fight.stats` 참고)
- 관리자가 `/fishing give rod <플레이어> <낚싯대ID> [개수]` 로 지급할 수 있습니다.

### 6. Modifier — 환경에 따른 확률 조정 🌍🌧️🌙
낚시하는 **장소나 상황**에 따라 등급별 확률을 조정할 수 있습니다.

| 조건 | 설명 |
|------|------|
| 월드 | 특정 월드에서 확률 조정 (예: 네더에서 S등급 확률 2배) |
| 바이옴 | 바다/강/숲 등 특정 지형에서 조정 |
| 날씨 | 맑음/비/뇌우에서 조정 |
| 시간 | 낮/밤에 따라 조정 |
| 권한 | 특정 권한을 가진 플레이어에게 조정 |

- 모든 조정은 **곱연산**으로 누적됩니다. (2.0 = 2배, 0.5 = 절반)
- `modifiers.yml`에서 설정합니다.

### 7. 도감(컬렉션) 시스템 📚
낚은 물고기를 도감에 **등록**하는 수집 시스템입니다.

- 물고기를 낚으면 도감에 “발견”으로 표시됩니다.
- 아이템을 소모하여 도감에 **등록**하면, 등록 칸이 채워집니다.
- 물고기마다 최대 등록 칸 수(기본 10칸)가 있으며, 가득 채우면 **퍼펙트** 완성입니다.

**보상 종류** (`collections.yml`에서 설정):
| 보상 | 조건 |
|------|------|
| 최초 등록 보상 | 물고기를 처음 도감에 등록했을 때 |
| 마일스톤 보상 | 특정 물고기를 일정 개수 등록했을 때 |
| 등급 올등록 보상 | 해당 등급의 모든 물고기를 1개 이상 등록 |
| 등급 퍼펙트 보상 | 해당 등급의 모든 물고기를 퍼펙트 완성 |
| 전체 완성 보상 | 모든 물고기를 퍼펙트 완성 |

- 보상은 콘솔 명령어 목록으로 지급됩니다. (`give`, `broadcast` 등)

### 8. 트로피 & 레어 트로피 🏆
물고기의 **특정 크기 이상**을 낚으면 트로피를 달성합니다.

| 트로피 | 조건 (기본값) |
|--------|----------------|
| 일반 트로피 | 평균 크기 × 1.5 이상 |
| 레어 트로피 | 최대 크기 × 0.9 이상 |

- 트로피는 물고기별로 **1회만** 지급됩니다.
- 트로피 획득 시 보상 명령어가 실행되며, 전체 서버에 알릴 수 있습니다.
- **트로피/레어 트로피를 낚으면 서버 전체에 공지**가 올라갑니다.
- **낚은 메시지에 등급(`[F]`, `[S]` 등)과 트로피 문구가 함께 표시**됩니다.
- 보유한 트로피 물고기는 `/fishing show` 로 다른 플레이어에게 자랑할 수 있습니다.
- **트로피/레어 트로피 물고기는 아래 “트로피 힘겨루기”를 성공해야 최종 획득**됩니다.

### 9. 랭킹 📊
도감/사이즈/트로피를 기준으로 서버 플레이어의 순위를 보여줍니다.

- **도감 랭킹**: 도감 점수(등록 칸, 퍼펙트, 트로피 가중치)
- **사이즈 랭킹**: 물고기별 가장 큰 사이즈 기록
- **트로피 랭킹**: 트로피 획득 수

- 랭킹 GUI는 `/fishing rank`로 열 수 있습니다.

### 10. 낚시 대회 🏅
서버에서 다양한 낚시 대회를 운영할 수 있습니다.

| 유형 | 우승 조건 |
|------|-----------|
| GRADE | 특정 등급 물고기를 많이 낚은 사람 |
| SIZE | 가장 큰 물고기를 낚은 사람 |
| COUNT | 가장 많이 물고기를 낚은 사람 |

- 특정 요일/시간에 **자동으로 시작**되거나, 관리자가 **수동으로 시작**할 수 있습니다.
- 참가비 설정, 최소/최대 인원, 순위별 보상, 참가상까지 지원합니다.
- 참가와 목록은 `/fishing tournament` 명령어로 확인합니다.

### 11. 🌊 트로피 힘겨루기(Trophy Fight)
**트로피 / 레어 트로피 물고기를 낚으면** 추가로 진행되는 실시간 힘겨루기 시스템입니다. 일반 미니게임 성공 후, 이 Fight를 성공해야만 비로소 트로피를 얻게 됩니다.

**핵심 수치**
| 수치 | 의미 |
|------|------|
| 물고기 체력(Stamina) | 0이 되면 물고기가 지침 |
| 물고기 힘(Power) / 저항(Resistance) | Fish AI 상태에 따라 변동 |
| 거리(Distance) | 0에 닿으면 회수 성공, 상한을 넘으면 줄 끊김 |
| 장력(Tension) | 줄 강도(Line Strength)를 넘으면 줄 끊김 |
| 릴 상태(Reel State) | 0이 되면 릴 파손 실패 |

**입력 시스템 — 좌클릭(릴 감기) vs 우클릭(릴 풀기)**
단순 연타가 아니라, 물고기의 상태를 보고 공격할지 회복할지 판단하는 리스크 관리 게임입니다.

| 입력 | 효과 |
|------|------|
| **좌클릭 (릴 감기)** | 물고기 체력 ↓, 거리 ↓, 장력 ↑, 릴 상태 ↓ |
| **우클릭 (릴 풀기)** | 거리 ↑, 장력 ↓, 릴 상태 회복 |
| **무입력 (아무것도 안 함)** | 물고기가 도망가 거리 ↑, 릴 상태 천천히 자연회복 |

**Fish AI 상태** — 물고기는 상황에 따라 다음 상태를 오가며 저항합니다: `휴식`, `천천히 이동`, `이동 중`, `방향 전환`, `돌진`, `마지막 발악`.

**좌클릭(릴 감기)의 상태별 효과**

| Fish 상태 | 거리 회수 | 장력 상승 | 체력 감소 |
|-----------|-----------|-----------|-----------|
| 휴식 | 보통 | 보통 | 보통 |
| 천천히 이동 | **많이** | 보통 | 보통 |
| 이동 중 | 보통 | 보통 | 보통 |
| 방향 전환 | 보통 | **더** | 보통 |
| 돌진 | 보통 | **많이** | **더 많이** |
| 마지막 발악 | 보통 | **많이** | **잘 안 줄어듦** |

**우클릭(릴 풀기)의 상태별 거리 증가** — 릴 회복량은 모든 상태에서 동일하지만, 물고기가 강하게 움직일수록 릴을 풀면 훨씬 멀리 도망갑니다.

| Fish 상태 | 거리 증가 |
|-----------|-----------|
| 휴식 | 매우 적음 |
| 천천히 이동 | 적음 |
| 이동 중 | 보통 |
| 방향 전환 | 다소 큼 |
| 돌진 | 큼 |
| 마지막 발악 | 매우 큼 |

**밸런스 규칙**
- `마지막 발악` 이후에는 반드시 `휴식` 상태가 나옵니다 — 발악으로 깎은 체력 보상을 잡아내는 타이밍을 줍니다.
- 등급이 높을수록(특히 레어 트로피) 물고기 스탯이 크게 올라가 어려워집니다.

**승리/패배 조건**

| 결과 | 조건 |
|------|------|
| ✅ 성공 | 거리 ≤ 0 이고 물고기 체력 ≤ 0 |
| ❌ 패배 | 장력 ≥ 줄 강도(줄 끊김), 거리 ≥ 상한(도망), 릴 상태 ≤ 0(파손), 제한 시간 초과 |

- Fight 진행 화면: BossBar(장력 게이지 + 거리) / ActionBar(체력·힘·저항·릴 상태)
- Fight 중 이동이 제한됩니다.
- `/fishing testfightmode on` 으로 **모든 입질을 트로피 파이트로 강제 전환**해 테스트할 수 있습니다(아래 명령어 참고).

### 12. 어망(Net) 시스템 🥅
낚은 물고기를 한데 모아 보관·정렬·꺼낼 수 있는 보관함 GUI입니다.

- `/fishing net` 으로 어망을 엽니다.
- 물고기 아이템을 보관/정렬/꺼내며 수집을 관리할 수 있습니다.
- 어망 아이콘에는 **등급 · 사이즈 · 트로피/레어 여부 · 잡은 시간**이 표시됩니다.
- **양방향 이동 지원**: 어망(위쪽)의 물고기 클릭 → 인벤토리로 꺼내기, 인벤토리(아래쪽)의 물고기 클릭 → 어망에 넣기.
- **크기는 어망에서만 표시**됩니다 (인벤토리 아이템에는 트로피/레어 여부만 표시).

### 13. 피로도 & 자동 낚시 ⚡
- 물고기를 낚을수록 **피로도**가 누적되어 자동 낚시 효율이 제어됩니다.
- `/fishing fatigue` 로 본인 피로도를 확인합니다.
- 피로 회복 물약 아이템(물고기)도 존재하며, 관리자가 `/fishing give` 로 지급할 수 있습니다.

### 14. 외부 플러그인 연동 🔌
설치되어 있으면 자동으로 연동됩니다. (없어도 기본 기능은 동작)

- **MMOItems**: 물고기/낚싯대를 MMOItems 아이템으로 사용 가능
- **PlaceholderAPI**: 메시지에 플레이스홀더 사용
- **Vault**: 낚시 대회 참가비 등 경제 연동
- **WorldGuard**: 낚시 허용 구역 설정 지원
- **ProtocolLib**: 일부 연동 기능 지원

## 명령어

메인 명령어 `/fishing` (별칭: `/if`, `/낚시`)

### 일반 플레이어
| 명령어 | 설명 |
|--------|------|
| `/fishing collection` | 도감 GUI 열기 (별칭: `/fishing col`, `/fishing 도감`) |
| `/fishing rank` | 랭킹 GUI 열기 (별칭: `/fishing ranking`, `/fishing 랭킹`) |
| `/fishing net` | 어망 GUI 열기 (별칭: `/fishing 어망`) |
| `/fishing tournament` | 대회 목록/참가/순위 (하위: list, join, leave, gui, wins) |
| `/fishing list [등급]` | 등급별 물고기 목록 확인 |
| `/fishing minigame <on\|off>` | 개인 L/R 클릭 미니게임 켜기/끄기 |
| `/fishing fatigue` | 내 피로도 확인 |
| `/fishing show` | 손에 든 물고기를 서버 전체에 자랑합니다. |
| `/fishing info` | 플러그인 기본 정보 확인 |

### 관리자 (`infishing.admin`)
| 명령어 | 설명 |

## 설정 파일 가이드

플러그인 폴더(`plugins/InMc-Fishing/`)에서 모든 설정을 관리합니다. 각 파일의 역할은 다음과 같습니다.

| 파일 | 역할 |
|------|------|
| `config.yml` | 기본 설정(월드/효과음/확률/메시지/화면 표시) + **trophy-fight 힘겨루기 설정** |
| `grades.yml` | 등급별 확률, 클릭 수, 제한 시간 |
| `items/f-grade.yml` ~ `items/s-grade.yml` | 등급별 물고기/보상 아이템 목록 |
| `items/rod.yml` | 낚싯대 종류, 보너스, Fight 스탯(릴 파워/줄 강도/릴 내구도) |
| `modifiers.yml` | 월드/바이옴/날씨/시간/권한별 확률 조정 |
| `collections.yml` | 도감 보상, 랭킹, 트로피 설정 |
| `tournaments.yml` | 낚시 대회 종류와 일정 |
| `worldguard.yml` | WorldGuard 낚시 허용 구역 설정 (설치 시에만) |
| `mmoitems-example.yml` | MMOItems 연동 예시 |

### Trophy Fight 설정 (`config.yml` → `trophy-fight:`)

| 항목 | 기본값 | 설명 |
|------|--------|------|
| `enabled` | true | 시스템 활성화 |
| `max-time-seconds` | 120 | 제한 시간(초), 체력 0이면 일시정지 |
| `particle-interval` | 2 | 파티클 출력 주기(틱) |
| `hud.*` | - | BossBar/액션바 색상·포맷 |
| `sound.*` | - | 상황별 사운드 (돌진/과부하/장력위험/지침/성공) |
| `stats.default-stamina` | 100.0 | 물고기 기본 체력 |
| `stats.default-distance` | 100.0 | 기본 거리 |
| `stats.max-distance` | 250.0 | 거리 상한(도망/줄 끊김) |
| `stats.max-tension` | 100.0 | 장력 최대값 |
| `stats.default-reel-state` | 100.0 | 릴 상태 기본값 |
| `stats.default-reel-power` | 30.0 | 기본 릴 파워(미등록 낚싯대 fallback) — 낮으면 물고기 체력 소모가 약해지고 거리가 잘 줄지 않음 |
| `stats.default-reel-durability` | 30.0 | 기본 릴 내구도(미등록 낚싯대 fallback) |
| `stats.grade-difficulty` | f:0.5 ~ s:2.5 | 등급별 난이도 배수 (레어 트로피는 추가로 어려움) |

### 간단한 설정 예시

**새 물고기 추가** — `items/f-grade.yml`에 항목만 추가하면 됩니다.

```yaml
items:
  new_fish:
    id: "new_fish"
    use-type: vanilla
    vanilla-material: COD
    vanilla-name: "&3새로운 물고기"
    vanilla-lore:
      - "&7새로 추가된 물고기입니다."
    min-size: 10.0
    max-size: 80.0
    avg-size: 35.0
    custom-model-data: 1101
    weight: 20
    double-enabled: true
    commands: []
```

**확률 조정 예시** — 비 오는 날 S등급 확률을 높이려면 `modifiers.yml`:

```yaml
weather:
  RAIN:
    grade-weight-multiplier:
      S: 1.5
```
